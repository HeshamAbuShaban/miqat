# The figures

**مِقياس الميقات** (`miqat-meter.html`) — the app's idea drawn as an
instrument: the plate carries the horizon (the arc from Fajr to Isha), the ticks
are the six prayers, the disc riding the arc is the sun at the day's real
progress, and the dial reads what is left.

Built with the [`anatomy`](https://github.com/wheresryan22/anatomy) skill (MIT),
which is installed on this machine for OpenCode, Antigravity, Codex and MiniMax
Code. Rebuild:

```sh
node docs/figures/build-miqat-meter.mjs
```

The page is self-contained (no network): open it in any browser.
